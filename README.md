# uma-musume-golden-generation

🌟 Tentang Proyek Web: Golden Generation Portal

Halo! Jika kamu penasaran kenapa situs web bertema Uma Musume: Pretty Derby khususnya karakter Grass Wonder dan kawan-kawan Golden Generation (黄金世代) ini dibuat, berikut adalah penjelasan singkatnya:

1. Apa Proyek Ini?

Ini adalah portal web fan-made interaktif yang didedikasikan untuk generasi kuda pacu legendaris tahun 1998 (Golden Generation) dalam waralaba Uma Musume, dengan fokus khusus pada karakter Grass Wonder (グラスワンダー) beserta galeri kostum, biografi, trivia, hingga sistem tata surya orbit (Solar Orbit System).

2. Kenapa Dibuat? (Proyek "Gabut" Berfaedah)

Iseng Berhadiah Karya: Proyek ini awalnya dimulai sekadar sebagai proyek iseng (gabut) untuk mengisi waktu luang dengan bereksperimen menggunakan Tailwind CSS, efek Glassmorphism modern, dan animasi Canvas HTML5.

Eksplorasi Teknologi Web: Menyatukan estetika anime, galeri karusel interaktif 4 versi kostum (Racing Outfit, Alt Costume, School Uniform, dan Casual Wear), serta simulasi orbit planet tata surya tanpa framework yang berat.

Kecintaan pada Uma Musume: Mengabadikan momen sejarah kuda pacu nyata tahun 1998 (seperti persaingan sengit Grass Wonder vs Special Week di Arima Kinen) ke dalam bentuk antarmuka web yang estetik dan informatif.

3. Fitur Unggulan dalam Web Ini

🌸 Efek Visual Animasi Canvas: Animasi sakura gugur dan partikel kosmik yang berjalan ringan di latar belakang.

🪐 Focus Orbit Mode: Simulasi tata surya interaktif di halaman utama (index.html) untuk menelusuri 5 bintang Golden Generation.

🎠 Multi-Version Outfit Carousel: Navigasi galeri kostum lengkap dari berbagai iterasi game dan anime.

📱 Fully Responsive: Dirancang agar nyaman diakses lewat perangkat seluler maupun komputer desktop.

Dibuat dengan secangkir kopi dan dedikasi penuh untuk para Trainer Uma Musume di seluruh dunia! 🐎✨
